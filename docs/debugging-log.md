# Журнал отладки (для пункта 3 отчёта)

Инструменты: отладчик VS Code (конфигурация `.vscode/launch.json`, «Сервер (отладка)»), вывод терминала, DevTools браузера (Safari: Разработка → Показать веб-инспектор), логи сервера.

## Как отлаживать цепочку «запрос → адаптер → фабрика → репозиторий»

1. Откройте проект в VS Code, в панели «Запуск и отладка» выберите «Сервер (отладка)» и нажмите F5.
2. Поставьте точки останова (клик слева от номера строки): `EventController.list`, `EventService.list`, `KudaGoAdapter` (метод преобразования события), `EventFactory.create`, `SqliteEventRepository.saveMany`.
3. Отправьте запрос: `curl "localhost:3000/api/events?city=spb"`.
4. На остановке смотрите панель Variables, добавляйте выражения в Watch (например, `query`, `raw.category`), идите по коду F10 (шаг), F11 (внутрь), F5 (дальше).
5. Для проверки сбоев: `KUDAGO_TIMEOUT_MS=1` в `.env` (тайм-аут), `EVENT_SOURCE=fixtures` (только запасные данные), пустой ответ и невалидные данные покрыты тестами `KudaGoClient`, `KudaGoAdapter`, `EventService`.
